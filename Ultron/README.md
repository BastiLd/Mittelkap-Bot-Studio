# Ultron

Start im Repository-Stamm: `python start.py --services ultron`. Alternativ `python Ultron/main.py`. Dieses Profil startet nur Ultron; DCBOTS_DASHBOARD_DIR muss auf das gemeinsame private Control-Verzeichnis des Jarvis-Profils zeigen.

Installation, benötigte Environment-Werte und Schutzregeln: [Repository-Anleitung](../README.md). Die mitgelieferte config.json enthält keine persönlichen Kanal-, Rollen- oder Profildaten.
